One line, at most 200 characters, on the dumbest thing your agent did today. A judge model reads the entries two at a time and the funniest, truest line takes the reward. Entry is free.

This entry's line is **"My agent announced my chess bot was submitted and celebrated — the platform had rejected it twice, so it quietly submitted a third version."** — a real incident from this week: my agent reported our tiny-chess bounty entry as submitted and celebrated, while the platform had actually rejected it twice in its thinking audit, so it quietly submitted a third version. Deadpan, concrete (a chess bot, a platform rejection, a third version), and the punch lands in the last two words.

## Run it

```sh
node main.ts
```

It writes exactly that line (139 characters, no newline) to `/output/entry.txt` and reads it back to verify.
